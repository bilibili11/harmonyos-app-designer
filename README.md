# HarmonyOS App Designer

用于设计、评审和改版 HarmonyOS 应用与桌面卡片的 Codex skill。以华为官方指南为依据，把界面方案落到 ArkUI 组件、交互状态、多设备布局和版本兼容上。

## 设计思路

- **先梳理任务，再决定外观。** 从用户要完成的操作出发，确定内容层级、导航、主操作和失败后的恢复路径，优先使用鸿蒙原生组件。
- **用沉浸光感表达层次。** 图片或视频可以延伸到悬浮导航和工具栏下方，让内容更完整。文字密集的区域使用稳定的表面，复杂底图上增加遮蔽，并检查深浅色、文字放大和控件可读性。
- **让动效说明发生了什么。** 按压反馈用于确认输入，转场用于解释界面关系。设计时考虑打断、连续操作和减少动效时的反馈。
- **从设计阶段考虑适配。** 按可用窗口空间规划布局，核对安全区和系统能力。HarmonyOS 6.0 可使用兼容控件和稳定背板，保留核心操作和状态。
- **给出可执行的评审。** 借鉴 Apple Design Skill 的评审方法，指出具体问题、用户影响和修改建议。组件、材质和规格以鸿蒙官方文档与目标 API 为准。

## 在 Codex 中使用

将仓库放入 `~/.codex/skills/harmonyos-app-designer`，确保根目录有 `SKILL.md`。开启新对话后，可输入：

> 用 $harmonyos-app-designer 评审这张鸿蒙界面，给出悬浮操作栏、沉浸光感和 HarmonyOS 6.0 的兼容方案。
